Shared procedure

How a trial runs

Both tasks use the same four beats. Only the math content and the step size of the span rule differ.

1

Solve

Items appear one at a time — a multiplication problem, or a pair of fractions to compare.

2

Hold

Each answer is retained while the student moves on to the next item in the sequence.

3

Recall

Once the sequence ends, the student enters every answer in the order it was presented.

4

Review

The trial's items reappear briefly, each shown with its correct answer.

In a scored set nothing is marked right or wrong as students work. The correct answers appear only after recall, and never for the recall order.

Two tasks

What students work on

Each task runs for five minutes and records the same measures. They differ in content and in how quickly the span moves.

Adaptive load

The span follows the student

Every student starts by holding two answers. The load climbs after a run of correct sequences and steps back down after a run of incorrect ones.

Study design

Onboarding and conditions

Lessons 1–3

A 2-minute practice trial comes first

Before training begins, the computer runs a short practice trial that marks every answer right or wrong and shows the correct order after recall, so every student understands the procedure before the first scored set.

  • ✓Each calculation or comparison marked right or wrong
  • ✓The correct recall order shown
  • ✓Runs only in the first three lessons

Two conditions

Same problems, different memory load

Both conditions see the same items in the same order. Only the requirement to retain and recall separates them.

  • ✓ Fraction + working memory — hold every answer, then recall the sequence in order
  • – Fraction only — state each answer as it comes, with nothing to retain or recall
